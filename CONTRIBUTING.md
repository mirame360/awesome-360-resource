# Contributing to Awesome 360° Resources

Thanks for helping make this list better! A few simple rules keep it useful for everyone.

## What belongs here

- Tools, libraries, platforms, cameras, specs, tutorials, and communities related to **360° photo/video, panoramas, virtual tours, and the immersive web**
- Resources that are **actively maintained** (or timeless references)
- Things you have **actually used** — this is a curated list, not a search-engine dump

## What doesn't

- Dead projects, abandoned repos, or link-farm articles
- Pure marketing pages with no substance
- Duplicates of something already listed (improve the existing entry instead)

## How to add an entry

1. Fork the repo and edit `README.md`
2. Add your entry to the correct section, alphabetical order is not required but related items should sit together
3. Use the format:

   ```
   - [Name](https://example.com/) — One-line description ending with a period.
   ```

4. Keep descriptions factual: say what it does, not how amazing it is
5. Open a pull request with one entry (or one coherent group) per PR, and a sentence on why it belongs

## Fixing things

Broken link, wrong description, better category? PRs for fixes are always welcome — small ones get merged fastest.
